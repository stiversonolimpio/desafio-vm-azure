## ⚙️ Etapas para criar uma VM no Azure (via portal)

1. Acessar o [portal do Azure](https://portal.azure.com)
2. Clicar em **"Máquinas Virtuais"** no menu lateral
3. Selecionar **"Criar" > "Máquina Virtual"**
4. Preencher os dados obrigatórios:
   - Assinatura e grupo de recursos
   - Nome da VM
   - Região (ex: Brazil South)
   - Imagem do sistema operacional (Windows/Linux)
   - Tipo de autenticação (senha ou chave SSH)
5. Escolher o tamanho da VM (ex: B1s para testes)
6. Configurar disco e rede (usar padrões para ambientes de teste)
7. Revisar e criar a VM

 Deixe as configurações padrão em um primeiro momento para agilizar o processo, e vá personalizando conforme seu conhecimento for evoluindo.

Estrutura do repositório
As imagens da criação da VM e suas configurações podem ser encontradas na pasta `/images`.

 Dicas úteis

- Use a **calculadora de preços do Azure** para entender custos antes de criar recursos em ambientes reais.
- O **Azure App Service** é ótimo para hospedar aplicações sem precisar gerenciar VMs.
- Monitore sua **assinatura gratuita** para não ultrapassar os limites e evitar cobranças.
- Você pode usar o **Azure Cloud Shell** para criar e gerenciar recursos via CLI diretamente pelo navegador.
